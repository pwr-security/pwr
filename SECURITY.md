# Security Policy

## What to report

Please report privately:

- A vulnerability in the tools or the workflows or the website of this project.
- Personal data published by mistake.

The weaknesses described in the registry are not vulnerabilities of this project. Corrections to entries go through a normal pull request.

## How to report

Use GitHub's private vulnerability reporting (the Security tab of this repository), or write to [mateo@callec.net](mailto:mateo@callec.net). Do not open a public issue or pull request for these reports.

Describe what you found and how to reproduce it. We aim to acknowledge a report within 7 days, and to tell you what we decide.

## Supported versions

Only the current state of the `main` branch is supported.
